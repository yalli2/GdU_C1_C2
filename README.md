# Gramática en Clase · GdU C1–C2

*Gramática de uso del español* (C1–C2) 1~106과를 정리한 인터랙티브 학습 사이트입니다.

- **메인 페이지**: `index.html` — 106개 단원 카드, 검색, 학습 진도 표시
- **단원 페이지**: `Unidad1/` ~ `Unidad106/` — 한국어 문법 정리, 예문 듣기(TTS), 연습문제, 채점(점수·정답·해설)
- 연습문제는 교재의 문법 항목에 맞춰 새로 구성했습니다. (총 약 1,815문항)
- 악센트 누락은 부분 점수, 학습 기록은 브라우저(localStorage)에 저장됩니다.

## 사용
GitHub Pages: `https://yalli2.github.io/GdU_C1_C2/`
각 단원은 `https://yalli2.github.io/GdU_C1_C2/UnidadN/` 형식입니다.
